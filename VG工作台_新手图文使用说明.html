01 · 第一次使用，准备好这三件事

  1. 启动工作台。双击 VG工作台.exe，浏览器会打开工作台。若未自动打开，访问 http://127.0.0.1:8765。
  2. 准备 Chrome 账号。在 Chrome 中登录用于制作视频的豆包账号。工作台读取这台电脑已有的 Chrome 用户资料。
  3. 切到「制作任务」。当前首页先显示「账号管理」，点击上方「制作任务」开始。点「1. 选择提示词」后，首次使用会准备桌面VG和内置样例。

工作台自动做什么？

读取脚本、确定时长、分配账号、导入提示词与全部参考图、同步可下载视频、批量保存成片。

你需要做什么？

准备变体和图片，首次给各账号安装插件；在豆包确认模式、时长和内容，点击发送并检查结果。

先用内置样例跑通一批，再替换成自己的脚本和图片。工作台需要保持运行，插件才能读取任务和同步视频。

02 · 文件这样放，时长和参考图就确定了

固定结构：VG / 秒数 / 脚本文件夹。秒数目录用 5秒、10秒、15秒。每个脚本文件夹中放多个提示词文件，以及一个名为「产品参考图」的文件夹。

内容规则
提示词支持 .md 和 .txt；一份文件是一份变体，文件名可以自定义。
视频时长按秒数目录决定。10秒目录中的任务全部按10秒，提示词内的时间戳不会改变任务时长。
参考图上传当前脚本「产品参考图」中的全部PNG、JPG、JPEG、WEBP图片，包含子文件夹；按相对文件名排序，不按提示词筛选。
图片隔离只取当前脚本的图。没有这个目录或目录内没有图时，只填提示词。

同名但路径不同的图分别上传；文件夹内放几张，工作台就尝试导入几张。不要把无关图片放进去。

不同参考图属于不同脚本文件夹。改变时长时，把整个脚本文件夹移到对应秒数目录，再重新添加任务。

03 · 首次安装VG插件

第一次打开尚未安装插件的账号，工作台会显示安装引导。每个Chrome账号都需要安装一次。

  1. 点击「① 打开扩展安装页」，在对应账号的Chrome中打开扩展管理，开启「开发者模式」。
  2. 点击「② 打开插件文件夹位置」，资源管理器会选中 vg_extension 文件夹。
  3. 把整个 vg_extension 文件夹拖进扩展安装页。若拖动没有安装，可点扩展页的「加载已解压的扩展程序」并选择该文件夹。
  4. 确认插件已启用，回工作台点击「③ 已安装，检查并继续」。
务必装在当前任务分配的Chrome账号中。装在另一个账号里，这个任务仍会提示未安装。

更新工作台后，若旧豆包页面仍用旧规则，在Chrome扩展页重新加载VG插件，再刷新豆包页面。安装时不要选择文件夹里的单个文件。

04 · 批量添加脚本变体

  1. 进入「制作任务」，点击「1. 选择提示词」。
  2. 从左侧选择秒数分类下的脚本，再选放提示词的文件夹。提示词直接放在脚本内时，选择「产品根目录」。
  3. 勾选需要的变体，或点「全选本目录」。可用搜索框按文件名查找。
  4. 默认每份生成1次。单个变体可用 − / + 调整；批量调整时，先勾选，再填写「所选各生成」并点「应用」。
  5. 确认底部数量，点击「添加到制作任务」。新任务追加到列表，自动分配可用账号，最新任务排在前面。
数量怎么算：3份提示词 × 每份2次 = 6条任务。每条任务都使用同一脚本的整套参考图。

额度不足时会留下待分配任务。先检查账号余额和禁用状态，再选择可用账号。再次点击添加会新增任务，不会替换上次的任务。

05 · 批量导入豆包，然后逐页发送

  1. 在工作台勾选要制作的任务，也可点「勾选全部【待发送】」，然后点顶部「2. 打开豆包」。
  2. 工作台按分配账号打开任务页面；缺少插件时先按上一节安装。等待右下角VG助手导入完整提示词和参考图。
  3. 在每个豆包任务页面检查提示词、图片、视频生成模式和时长。确认后在豆包点击发送。
  4. 保持工作台运行，并保留豆包任务页面，等待视频生成和插件同步。
不要把「生成中」当作发送成功凭据。当前版本在导入成功时就可能把工作台任务标成生成中，仍要到豆包确认已点击发送。

导入失败时，等输入框完全加载，再点右下角VG助手的「重新自动导入」；只需复制文字时点「拷词」。重新导入前检查已有图片，避免重复添加。

页面标题中的[V01]、[V02]等编号对应工作台任务，切换多个页面时可用它核对。

06 · 一次下载多个成片

  1. 先查看「成片下载至」。点「修改路径」选择保存目录，也可粘贴完整路径后按回车。
  2. 切到「视频就绪（可下载）」，点「全选当前视图」；只下载部分视频时，逐条勾选。
  3. 点击顶部「3. 下载成片」，确认下载清单。工作台会逐条下载，显示进度与成功数量。
  4. 完成后点「打开成片目录」查看文件；已下载任务会出现「预览」按钮。
下载全部的方法：视频就绪 → 全选当前视图 → 下载成片。当前版本必须先勾选，不会在未勾选时自动下载全部。

未就绪的视频需要继续等待。下载失败的任务会保留勾选，方便再试。需要统一保存位置时，使用工作台下载；豆包页VG助手的「下载视频」走Chrome下载管理器，保存位置由浏览器决定。

部分旧提示文案仍写“成品/素材”；实际保存位置以「成片下载至」和下载完成结果为准。

07 · 账号、任务与历史记录

操作何时使用 / 怎么做
打开此号在「账号管理」中打开对应Chrome账号，用于登录豆包或核对实际额度。
校准额度工作台次数与豆包不一致时，填写实际5秒、10秒、15秒剩余次数并保存。
禁用 / 重新启用暂时不用某个账号就禁用。该账号不再参与分配，尚未发送的关联任务会解绑。
重置今日剩余次数把工作台记录恢复为默认次数。每日00:00（UTC+8）也会自动重置；这不会增加豆包实际额度。
筛选 / 勾选按待发送、生成中、视频就绪、已下载查找任务。「全选当前视图」只勾选当前筛选显示的任务。
查词 / 复制全文在任务行点「查词」查看提示词，弹窗中点「复制全文」可复制正文，用于核对或手动粘贴。
账号下拉框尚未发送的任务可选择可用账号。额度不足时先校准或启用其他账号。
删除勾选 / 垃圾桶删除一批或单条任务。「清空列表」移除当前全部任务记录，不是删除已保存的视频。
历史记录查看自动保存的任务快照，恢复误删前的列表。恢复会替换当前列表，先确认要保留哪些任务。
刷新数据更新账号和任务信息。插件或文件位置改变后，可用它重新读取。

未发送任务会预留额度，分配结果还取决于当前已有任务。余额数字是工作台记录，豆包实际能否生成以豆包页面为准。

08 · 遇到问题，先看这里

看到的情况先做什么
网页打不开 / 空响应确认EXE还在运行，再访问127.0.0.1:8765；重新启动工作台后刷新页面。
提示词列表没有文件确认文件在VG/5秒、10秒或15秒/脚本文件夹内，后缀为.md或.txt。点刷新，再重新打开选择窗口。
尚未检测到插件核对当前Chrome账号和插件启用开关。新安装后等几秒，点击「已安装，检查并继续」。
提示词为空 / 未成功导入检查文件存在且有正文；移动或改名后重新添加任务。等待豆包加载，核对[Vxx]任务编号，再点「重新自动导入」。
图片缺少或没有图片检查任务对应脚本下的「产品参考图」，核对格式。豆包页面若提示数量或上传限制，按其提示调整图片；导入后目视核对。
任务没有分配账号检查账号是否被禁用、对应秒数额度是否足够，必要时校准额度并选择可用账号。
豆包已出片，工作台未就绪保留或刷新对应豆包任务页，确认VG插件运行；等几秒后刷新工作台。插件同步后才会进入可下载。
下载失败 / 找不到文件检查网络和「成片下载至」，重新勾选失败任务下载。用「打开成片目录」定位，不要只找旧的素材目录。
换电脑：复制EXE即可首次准备样例和插件，但Chrome账号需要在新电脑登录、安装插件。迁移旧任务时同时保留data和对应VG素材；登录状态不会随EXE自动迁移。
