# VG 视频制作工作台

修改项目之前完整阅读本文档。

## 当前工作流
人工按秒数目录分类 → 选择提示词 → 自动分配账号 → 勾选后打开豆包 → 下载 → 下载后预览。

## 文件目录和时长
默认读取桌面/VG，由人工把脚本文件夹放入对应的时长目录。

    桌面/VG/
      5秒/
      10秒/
        脚本名/
          产品参考图/
            1.png
            2.png
          提示词01.md
          提示词02.md
      15秒/

支持 .md/.txt。顶层5秒目录内全部按5秒，10秒内全部按10秒，15秒内全部按15秒，包括所有子文件夹。目录是唯一时长来源，不解析文本，不应用旧手动时长记忆，不弹确认。分类外的提示词阻止整批添加，提示移动到对应目录。已发送任务保留历史时长。
扫描器把时长分类下的产品/脚本分别显示，参考图按产品隔离。相同名称在不同分类中分别显示。

## 首次说明和样例
内置样例来自用户指定的 Desktop/VG，源资源在 resources/vg_example，打包为 vg_example。
首次点击初始化 POST /api/vg/initialize，复制缺少的样例文件，已有文件不覆盖。data/settings.json 的 vg_library_layout=duration-folders-v2 标记本版初始化。旧用户首次使用新版也会收到新结构说明。
POST /api/durations/resolve 按文件路径的顶层秒数目录返回规格。旧 /api/durations/confirm 禁用，提示通过移动目录改变时长。环境变量 VG_ROOT 可指定独立测试目录。

## 图片上传
从任务对应 VG/秒数/脚本文件夹/产品参考图 递归收集所有 PNG/JPG/JPEG/WEBP 图片，按相对路径排序。完整 Base64 直送所有图片，不按提示词筛选、不去重、不截取前10张，不跨脚本取图。没有图片时只填写提示词。插件和两份用户脚本同步实现此规则。

## 核心文件
- server.py：HTTP 服务、额度、目录扫描、时长设置、Chrome 启动和下载。
- public/index.html：账号与任务界面，首次说明、目录分类校验、安装引导。
- vg_extension/：Chrome 插件。EXE 启动将内置插件落地到同级 vg_extension。
- resources/vg_example/：内置简版样例。
- data/：额度、任务、设置、历史快照。
- build_exe.bat：打包前端、插件和样例。

## 运行与开发约束
服务端口固定 8765。开发运行 python server.py；分发运行 dist/VG工作台.exe。无控制台版本将输出写入 workbench.log。
每个 Chrome 账号首次安装插件一次，检测未安装时显示安装教程；用户点击按钮打开对应账号的扩展页，再打开并选中插件文件夹供拖动安装。
每天 UTC+8 零点重置默认额度，关闭期间下次启动补做。保留禁用状态，支持手动校准，额度日级备份在 data/quota_history。
任务修改必须经过 save_daily_tasks(..., make_snapshot=True)。仅唤起未发送任务，批量按账号聚合，保留失败任务勾选。
账号禁用必须排除自动与手动分配候选，自动解绑未发送任务。
下载逐条流式推进并显示卡片进度。视频归属必须明确 task_id，全局防重，保留插件发送后 15 秒防误判逻辑。
修改插件内容时遵守当前同步规则；不要更改端口、任务绑定和快照机制。

## 换电脑使用
EXE 可放在任意可写目录，首次启动自动准备数据和内置插件。只读安装目录会将数据、日志和插件保存至当前用户 LOCALAPPDATA/VGWorkbench。桌面通过系统配置读取，支持 OneDrive/重定向。Chrome 按当前用户和系统安装位置探测，可用 CHROME_PATH、CHROME_USER_DATA_DIR 指定自定义安装。账号来自当前机器 Chrome，本机插件仍需首次安装。
启动桥梁在数据目录 runtime/launch_account.bat，使用当前用户专属计划任务；注册失败时从当前桌面直接启动。Cookie 导出保存到 data/cookie_exports，辅助脚本从运行服务读取目录和账号。VG_ROOT 可指定素材根目录。
分发新的 EXE 即可自动准备样例和插件；迁移历史任务需同时复制 data 和对应 VG 素材。账号登录状态由 Chrome 管理，不随 EXE 自动迁移。
